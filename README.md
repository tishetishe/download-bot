# Download Telegram Bot

![Python Version](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)
![Telegram](https://img.shields.io/badge/Telegram-2CA5E0?style=for-the-badge&logo=telegram&logoColor=white)

## Фунционал

* **Скачивания фото , аудио , видео на популярных платформах**
* **Без водянных знаков**
* **Разделение формата**

## Поддерживаемые платформы

* **TikToK**
* **Instagram**
* **YouTube**

## Важно!

**Иногда заходить в TikTok(или на ту платформу через которую скачиваете) через браузер залогиненным(желательно через ПК) и пользоваться платформой и ботом некоторое время (буквально 15 минут), чтобы TikTok не блокировал действия и сохранялись куки**

## Устанновка и запуск

### 1)Клонирование репозитория
 ```bash 
 git clone https://github.com/tishetishe/download-bot 
 cd download-bot 
 ``` 

 ### 2)Настройка токена 
 Создайте файл `.env` в корневой папке проекта: 
 ```env 
 BOT_TOKEN=ваш_токен_от_botfather 
 ``` 

 ### 3)Запуск бота 
 ```bash python main.py ```
