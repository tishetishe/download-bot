## Фунционал

* **Скачивания фото , аудио , видео на популярных платформах**
* **Без водянных знаков**
* **Разделение формата**

## Поддерживаемые платформы

**TikToK**
**Instagram**
**YouTube**

## Важно!

**Иногда заходить в тикток с браузера залогинненым и скидывать ссылку с браузера что бы тикток не блокировал дейтвия бота**

## Устанновка и запуск

### 1)Клонирование репозитория
 ```bash 
 git clone https://github.com 
 cd имя-репозитория 
 ``` 

 ### 2)Настройка токена 
 Создайте файл `.env` в корневой папке проекта: 
 ```env 
 BOT_TOKEN=ваш_токен_от_botfather 
 ``` 

 ### 3)Запуск бота 
 ```bash python main.py ```
